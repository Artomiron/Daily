# Daily

Щоденник стану, думок та вдячності. PWA — можна додати на екран iPhone як окремий застосунок.

- **Сьогодні** — покрокова оцінка дня (психологічний стан → фізичний стан → що вплинуло на день → вдячність); психологічний стан — за циркумплексною моделлю (зона + слова, бали приємності та енергії від −5 до +5), фізичний — чотири питання на основі PROMIS (самопочуття, втома, біль 0–10, сон) з індексом тіла 0–100, самоаналіз — до двох факторів дня з напрямом 👍/👎 і необов'язковим «Чому саме?»; кнопка «💭 Думки» відкриває думки обраного дня
- **Задачі** — задачі на день, разові або з повтором (щодня, по буднях, у вибрані дні тижня, кожні N днів); чекбокс з анімацією, а коли виконано все — конфеті
- **Статистика** — середні значення, графік, серія днів поспіль, фактори, що найчастіше впливають на дні

Записи зберігаються лише в браузері на пристрої (localStorage). Резервну копію (записи й задачі) можна експортувати/імпортувати в налаштуваннях (⚙️).

## Встановлення на iPhone

Відкрити сайт у Safari → «Поділитися» → «На початковий екран».
