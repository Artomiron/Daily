# Daily

Щоденник стану, думок та вдячності. PWA — можна додати на екран iPhone як окремий застосунок.

- **Сьогодні** — покрокова оцінка дня (психологічний стан → фізичний стан → вдячність); психологічний стан — за циркумплексною моделлю (зона + слова, бали приємності та енергії від −5 до +5) і думки протягом дня
- **Історія** — усі записи з пошуком
- **Статистика** — середні значення, графік, серія днів поспіль

Записи зберігаються лише в браузері на пристрої (localStorage). Резервну копію можна експортувати/імпортувати в налаштуваннях (⚙️).

## Встановлення на iPhone

Відкрити сайт у Safari → «Поділитися» → «На початковий екран».
