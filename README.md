# Daily

Щоденник стану, думок та вдячності. PWA — можна додати на екран iPhone як окремий застосунок.

- **Щоденник** — покрокова оцінка дня (психологічний стан → фізичний стан → що вплинуло на день → вдячність); психологічний стан — за циркумплексною моделлю (зона + слова, бали приємності та енергії від −5 до +5), фізичний — чотири питання на основі PROMIS (самопочуття, втома, біль 0–10, сон) з індексом тіла 0–100, самоаналіз — до двох факторів дня з напрямом 👍/👎 і необов'язковим «Чому саме?»; кнопка «💭 Думки» відкриває думки обраного дня
- **Задачі** — задачі на день, разові або з повтором (щодня, по буднях, у вибрані дні тижня, кожні N днів); чекбокс з анімацією, а коли виконано все — конфеті; зіркові задачі наповнюють зірку (5 задач = 1 зірка), прогрес переходить між днями, є лічильник зірок на балансі; 🛍 Магазин — власні винагороди з ціною в зірках, купівля за баланс і архів покупок
- **Статистика** — окремо по щоденнику (стан, графік, серія днів, фактори) і по задачах (виконання, графік по днях, які задачі пропускаються)

Записи зберігаються лише в браузері на пристрої (localStorage). Резервну копію (записи, задачі й магазин) можна експортувати/імпортувати в налаштуваннях (⚙️).

## Встановлення на iPhone

Відкрити сайт у Safari → «Поділитися» → «На початковий екран».
